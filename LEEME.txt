CARRERA DE ADMINISTRACIÓN DE SERVIDORES E INFRAESTRUCTURA
==========================================================

Plataforma web interactiva con una carrera completa para llegar, desde cero, a trabajar
como administrador de servidores o analista de infraestructura: Linux, redes, Windows
Server, servicios, virtualización, automatización, contenedores, nube, seguridad y
práctica profesional. Todo el material de estudio vive dentro de la plataforma.

CÓMO SE MODIFICA EL PLAN
------------------------

El archivo docs/PLAN_DE_CARRERA.txt se genera a partir de:

  docs/plan/curriculo/nivel-0.yaml ... nivel-9.yaml   niveles, módulos y lecciones
  docs/plan/encabezado.txt                            introducción del plan
  docs/plan/anexos.txt                                certificaciones y fuentes

Después de editar esos archivos, regenerarlo con:

  python3 docs/plan/generar_plan.py

(Requiere Python 3 y PyYAML: pip install pyyaml.) El generador además valida que cada
lección tenga objetivos, horas e interactivo, que cada módulo tenga laboratorio y caso
real, que los requisitos entre módulos existan y que no haya texto de relleno. Para solo
validar y ver los totales:

  python3 docs/plan/generar_plan.py --check


CÓMO SE VA A CORRER LA PLATAFORMA
---------------------------------

A partir de la Etapa 2 (detalle en docs/ARQUITECTURA.txt, sección 11):

  npm install
  npm run dev        y abrir http://localhost:5173
