## Objetivo

Juntar todo el módulo en una herramienta que vas a usar de verdad: un script que recorre varios servidores y arma un informe en CSV (para filtrar y procesar) y en HTML (para mandar por correo) con los discos, los servicios automáticos que no están corriendo y la última actualización instalada. Es el tipo de script que todo equipo de sistemas tiene, y que después se programa para que corra solo todas las mañanas.

## Qué necesitás

- La plataforma para la parte 1.
- Para la parte 2: SRV-ADMIN y SRV-CORE01 del laboratorio del módulo 3.1 (con el segundo disco D: en SRV-CORE01), y Visual Studio Code con la extensión de PowerShell en SRV-ADMIN (o el ISE).
