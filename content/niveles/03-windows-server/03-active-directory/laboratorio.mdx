## Objetivo

Juntar todo el módulo en lo que vas a hacer de verdad cuando una empresa te pida "armá el dominio": dos controladores, una estructura de OU que sirva para administrar, cuentas creadas desde la planilla de Recursos Humanos, permisos por grupos, directivas de seguridad, unidades de red y una PC con Windows 11 que funciona con todo eso. Al terminar, tenés la base de los módulos 3.4 (archivos, DHCP y DNS) y 3.5 (actualizaciones y mantenimiento), y del proyecto del nivel.

## Qué necesitás

- La plataforma para la parte 1.
- Para la parte 2: tu hipervisor con lugar para tres máquinas virtuales más (DC01, DC02 y PC01, unos 8 GB de RAM entre las tres), SRV-ADMIN y SRV-CORE01 del módulo 3.1, y los ISO de evaluación de Windows Server 2025 y Windows 11 Enterprise.
