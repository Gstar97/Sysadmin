## Objetivo

Armar las dos piezas que vas a usar durante todo el nivel: un servidor con escritorio que hace de estación de administración (SRV-ADMIN) y un Server Core que se maneja solo a distancia (SRV-CORE01). Al terminar, vas a haber usado las cuatro herramientas del módulo sobre el mismo servidor, y vas a saber qué puertos y reglas necesita cada una.

## Qué necesitás

- Un hipervisor (Hyper-V, VirtualBox o VMware) con unos 6 GB de RAM libres y 140 GB de disco.
- El ISO de evaluación de Windows Server 2025 (180 días, gratis).
- La red del laboratorio del Nivel 2 (192.168.10.0/24), con salida a internet si querés instalar las actualizaciones. Si todavía no la tenés, alcanza con una red interna del hipervisor: usá las mismas direcciones y saltate el paso de actualizaciones.

## Para pensar

1. ¿Qué tareas te resultaron más cómodas con Windows Admin Center y cuáles con PowerShell? ¿Cuál usarías si tuvieras que hacer lo mismo en 20 servidores?
2. Las consolas MMC necesitaron reglas de firewall que PowerShell no necesitaba. ¿Qué te dice eso sobre por dónde se conecta cada herramienta?
