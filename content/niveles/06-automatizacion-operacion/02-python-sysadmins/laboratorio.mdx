## Objetivo

Juntar todo el módulo en una herramienta de verdad: lee su configuración, habla con servidores por dos caminos distintos (una API y SSH), sobrevive a los que fallan, deja un resultado para máquinas (JSON) y otro para personas (HTML), tiene pruebas y corre sola. Es el esqueleto de muchas herramientas internas de un equipo de infraestructura, y en el módulo 6.4 el monitoreo va a vigilar que siga corriendo.

## Qué necesitás

- La plataforma para la parte 1.
- Para la parte 2: tu VM de administración, dos o más VM a las que llegues por SSH con clave, y el repositorio lab-infra del módulo 6.1.
