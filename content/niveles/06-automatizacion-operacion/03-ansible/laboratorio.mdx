## Objetivo

Armar un proyecto de Ansible como los de una empresa: roles reutilizables que dejan un servidor web y uno de base de datos listos a partir de una instalación limpia, los secretos cifrados, una revisión automática de calidad y un playbook para Windows, todo en el repositorio del módulo 6.1. Al final, si mañana se rompe un servidor, lo volvés a dejar igual en minutos con un comando.

## Qué necesitás

- La plataforma para la parte 1.
- Para la parte 2: tu equipo de administración con Ubuntu, dos VMs con Rocky Linux 10 (web01 y db01), una VM con Windows Server 2025 de evaluación (win01) y el servidor de Git del módulo 6.1.
