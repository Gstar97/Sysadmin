## Objetivo

En la lección 0.4.4 viste que el cuaderno técnico es tu memoria de trabajo. En este laboratorio lo armas de verdad y lo estrenas con algo concreto: documentar el laboratorio del módulo 0.2 para que otra persona (o tú dentro de seis meses) pueda usarlo sin preguntarte nada. Si en los módulos anteriores ya venías anotando cosas, este es el momento de ordenarlas.

## Qué necesitas

- Las tres VMs del módulo 0.2 (`ubuntu01`, `rocky01` y `win2025`) encendidas, o al menos accesibles.
- Un editor de texto. Se recomienda Visual Studio Code, que muestra la vista previa de Markdown.
- Unas dos horas.

## Markdown en cinco minutos

Markdown es texto común con algunas marcas que se convierten en formato. Es el formato de la documentación de muchísimos proyectos y lo vas a usar toda la carrera:

````markdown
# Título principal
## Subtítulo

Texto normal, con **negrita** y `comandos` dentro de una línea.

- Un elemento de una lista
- Otro elemento

| VM       | IP              |
| -------- | --------------- |
| rocky01  | 192.168.56.102  |

```
bloque de código: varias líneas de comandos o de salida
```
````

## Plantillas

**Inventario del laboratorio** (`laboratorio/inventario.md`):

```markdown
# Inventario del laboratorio

Actualizado: 2026-10-27
Hipervisor: VirtualBox 7.2 en Windows 11 (16 GB de RAM)
Red solo anfitrión: 192.168.56.0/24 (mi PC: 192.168.56.1)

| VM       | Sistema y versión       | CPU | RAM  | Disco | IP solo anfitrión | IP NAT    |
| -------- | ----------------------- | --- | ---- | ----- | ----------------- | --------- |
| ubuntu01 | Ubuntu Server 26.04 LTS | 2   | 2 GB | 25 GB | 192.168.56.101    | 10.0.2.15 |

## Usuarios
- ubuntu01: ana (sudo). Contraseña en el gestor de contraseñas.

## Instantáneas
- instalación limpia (2026-10-12): recién instalada y actualizada, con SSH.
```
