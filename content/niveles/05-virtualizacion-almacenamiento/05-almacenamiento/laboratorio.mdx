## Objetivo

Usar las tres formas de almacenamiento del módulo en el mismo clúster y ver, con tus ojos, qué gana y qué pierde cada una cuando un nodo se cae: con ZFS y réplica, la VM vuelve con unos minutos de datos de menos; con el LUN iSCSI, todo depende de san01; con Ceph, no se pierde nada, pero el clúster queda degradado hasta que vuelve el nodo.

## Qué necesitás

- La plataforma para la parte 1.
- Para la parte 2: el clúster del laboratorio del módulo 5.4 (pve01 a pve03 y nfs01), unos 220 GB más de disco (se ocupan de a poco) y, si podés, 6 GB de memoria por nodo. Un Windows Server del Nivel 3 para el paso de Windows.

## Para pensar

1. Anotá, para cada una de las tres formas, qué se perdió y cuánto tardó la VM en volver cuando apagaste el nodo. ¿Cuál elegirías para el ERP de una empresa de 50 personas con tres servidores? ¿Y para su servidor web?
2. El LUN iSCSI lo sirve una sola VM (nfs01). ¿Qué tendría que tener una SAN de verdad para no ser el punto único de falla del clúster?
3. Con tres nodos, Ceph no pudo rehacer la tercera copia. ¿Qué cambia con cuatro? ¿Y qué pasa con el espacio libre que necesita para hacerlo?
